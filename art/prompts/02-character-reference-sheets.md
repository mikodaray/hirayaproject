# Character reference sheet prompts

Use these to generate one reference image per character. Save each result in art/characters/ as NN-name-sheet-vN.png and attach it as a reference image in future generations so the faces stay the same.

Status: DRAFT. Character sheets are in full color (the creator wants color for these, interior chapter pages stay black and white). Looks marked (DRAFT) are my suggestions, not decided by the creator.

## How to use
1. Paste the COMMON STYLE block first, then the character block.
2. Generate the main sheet. If the face is wrong, regenerate before moving on.
3. Once you like one, attach it as a reference and generate the expression sheet.
4. Save both in art/characters/ and note the version in art/README.md.

## COMMON STYLE (paste before every character)

Not realistic, not 3D, not painted. Plain white background. Full body character shown three times in a row: front view, side view, back view, all standing straight at the same height. No readable text, no labels, no logos. Setting of the story: modern Philippines, Durian Public High School.
