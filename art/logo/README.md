# HIRAYA logos

Extracted from the Chapter 1 cover 1 art (art/06-chapter-1-cover-1-warriors.png). Use this as the one logo everywhere.

- hiraya-logo.png : transparent background, gold letters with dark brown outline, sun symbol on top (671x220). Small gaps inside the sun ring and the A's are semi transparent.
- hiraya-logo-plain-crop.png : plain rectangular crop of the same area on the original cover background (fallback).

Do not redraw the title in other images. Composite this file on top (or attach it as a reference and say "use this exact logo").

## Style 2 (brush)
Extracted from Chapter 1 cover 2 (art/07-chapter-1-cover-2-classroom-fisheye.png).
- hiraya-logo-style2-brush.png : transparent background, dark brown ink brush letters, with the small Baybayin style mark beside the H. Dark ink, so use it on light backgrounds. The soft gold glow from the cover is not included.
- hiraya-logo-style2-plain-crop.png : plain crop on the cover background (includes the glow and a bit of the subtitle).
