# Hiraya

Hiraya is a manga, a Filipino historical adventure story. This repository is the home for everything about it.

## How this repository is organized
All story documents live in the `story-bible/` folder:

- `story-bible/01-premise.md`: the core idea, themes, tone, audience
- `story-bible/02-characters.md`: main cast, supporting cast, relationships
- `story-bible/03-world-and-history.md`: setting, era, places, culture, rules of the world
- `story-bible/04-plot-outline.md`: arcs, chapters, key scenes
- `story-bible/05-research-notes.md`: historical sources, references, facts to verify
- `story-bible/06-ideas-inbox.md`: loose ideas, to sort later

## Working rules
- Add to the inbox first, then move ideas into the right doc once decided.
- Mark anything undecided as OPEN so we know what still needs a choice.
- Mark historical facts as VERIFIED or TO CHECK.
